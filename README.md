# Soham Methe — Cinematic AI Engineer Portfolio

## Run locally
Open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

The cinematic background uses the 208 existing JPG frames in `public/frames/`. It fills the entire viewport and changes frames as the page scrolls down or up. Portfolio sections are layered transparently above it.

Keep the `public` folder, `index.html`, `styles.css`, and `script.js` together when moving or publishing the site.
